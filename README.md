# QY Player · 清玉播放器

一个 Windows 桌面本地音乐播放器。它只做一件事：把你电脑里已有的音乐文件整理成一个看得清的曲库，然后干净利落地放出来。不需要登录，不联网，不上传任何东西。

当前版本 **v1.1.1**。

## 下载与安装

两种形态任选其一，功能完全一样，区别只在「装不装」。

| | 便捷版（zip） | 安装版（setup.exe） |
|---|---|---|
| 大小 | 约 107 MB | 约 75 MB |
| 是否需要安装 | 解压即用 | 双击安装，带卸载入口 |
| 数据存放 | 程序文件夹内 | 见「数据存在哪」 |
| 适合 | 放 U 盘、放 D 盘、不想动系统 | 想要开始菜单图标与文件关联 |

**便捷版**：把压缩包解压到任意文件夹，双击里面的 `QYPlayer.exe` 就能用。整个文件夹可以随意搬动或拷到 U 盘，播放记录、设置和曲库都跟着走。

**安装版**：双击 `setup.exe`，按提示下一步到底。安装向导是中文的，全程不需要管理员权限，也不会弹 UAC 授权框。装完之后开始菜单里有快捷方式，控制面板里能正常卸载。

> 系统要求：Windows 10 1809 或更新版本、Windows 11，64 位。程序自带运行环境，不需要另外装 .NET 或任何播放器组件。

## 第一次使用

打开程序，左边是曲库，右边是播放区。曲库一开始是空的，两种方式把它填满。

点左栏的**「添加文件夹」**，选一个你放音乐的文件夹，程序会把里面的歌全部找出来（子文件夹也会翻）。之后你往这个文件夹里丢新歌，曲库会自动跟着更新，不用再手动操作一次。

或者把音乐文件、文件夹直接**拖进窗口**，立刻就能放。也可以点**「打开文件」**单独挑几个文件来听，这条路不经过曲库，适合临时试听。

列表里**双击任意一首**开始播放。正在播放的那一行行尾会出现跳动的音符，一眼能看出来放到哪儿了。

## 快捷键

| 按键 | 作用 |
|---|---|
| `空格` | 播放 / 暂停 |
| `Ctrl` + `O` | 打开文件 |
| `Ctrl` + `S` | 停止 |
| `Ctrl` + `M` | 静音 / 恢复 |
| `Ctrl` + `←` / `Ctrl` + `→` | 上一首 / 下一首 |
| `Ctrl` + `R` | 切换播放模式 |

进度条和音量条都可以**单击直接跳到那个位置**，不必先拖住滑块。点进度条之前的位置也可以往回跳。

播放模式按钮在停止键旁边，按一下换一种，顺序是：顺序播放 → 列表循环 → 单曲循环 → 随机播放。

## 支持的格式

可以直接播放的常见格式：MP3、FLAC、WAV、M4A/AAC、OGG、OPUS、WMA、APE、ALAC。

标题、艺术家、专辑、时长和封面会从文件标签里读出来（FLAC、MP3 等主流格式都带标签）。读不到标签时，就用文件名当标题，不会出现空白行。

加密格式（NCM、KGM、KWM、VPR）默认不支持。这类文件需要单独安装解密插件，插件放在程序目录的 `plugins` 文件夹里，放进去重启程序就生效。为了合规，插件不随播放器一起提供。

## 界面上的几件事

曲库栏占 340 像素。如果嫌它挤，点栏头最左边的按钮可以**把它收成一条窄边**，播放区立刻变宽；再点一下展开。收起状态会被记住，下次打开还是收起的。

搜索框在栏头下面，输入即过滤，能按标题、艺术家、专辑或文件名找。搜索没结果时列表会提示「没有匹配的曲目」，曲库本身没有被动过。

曲库列表是虚拟化的，几万首也不会卡。

程序**同时只开一个窗口**。你已经开着一个 QY Player，再从资源管理器双击一首歌、或者一次选中十个文件右键「打开方式」，这些歌都会被送进已经开着的那个窗口按顺序播放，不会弹出一排窗口。一次交给它一批文件和文件夹，它会按你点选的顺序展开文件夹、依次播下去。

## 数据存在哪

程序启动时会先试着在程序目录里写个临时文件，用能不能写成功来决定数据放哪。

便携版、或者装在你自己有权限的目录里，数据就在程序目录下的 `data` 文件夹：

```
data/settings.json      音量、播放模式、主题、曲库文件夹、窗口位置
data/db/library.db      曲库索引（歌曲信息、封面路径）
data/covers/            从歌曲里提取出来的封面图
data/logs/              运行日志，按天一个文件
```

整个文件夹拷走，这些设置和曲库也跟着走。

如果装在 `Program Files` 这类你没权限写的地方，程序会自动改用 `%LOCALAPPDATA%\QY Player\data`（在资源管理器地址栏输入这个路径就能打开）。这样一来，无论装到哪儿都不会因为权限问题启动失败。

**卸载时**会问你要不要连数据一起删，默认是保留。删了没法找回，而留着下次重装还能接着用，所以默认不删。静默卸载不会弹窗，按保留处理。

## 常见问题

**换了版本以后，资源管理器里还是旧图标。**
Windows 的图标缓存是按文件路径记的，程序覆盖安装后路径没变，它就沿用旧记录。仓库里备了一个脚本，在 PowerShell 里执行 `build\refresh-icon-cache.ps1` 即可重建缓存。屏幕会闪一下，资源管理器重启后自动恢复。

**启动时弹窗说 libVLC 原生库加载失败。**
通常是把 `QYPlayer.exe` 单独拷出来用了。程序依赖同目录下的 `libvlc\win-x64`，请整个文件夹一起移动。另外确认一下系统是 64 位，这个程序没有 32 位版本。

**加的文件夹里明明有歌，曲库里却没有。**
先确认文件扩展名在上面「支持的格式」里。程序会跳过没有读取权限的子文件夹，不会因此中断整次扫描，但这部分内容就不会进曲库。另外加密格式要装插件才能识别。

**播放没声音。**
先看右下角音量滑块旁边的喇叭图标是不是静音状态，再按 `Ctrl+M` 切一下。播放引擎的声音走系统默认输出设备，如果换了耳机或音箱，在 Windows 的声音设置里确认默认设备是你想用的那个。

**嫌封面缓存占地方。**
封面缓存有总容量上限，超出时会自动淘汰最久没用的那些，不需要手动清理。真想清空，直接删掉 `data/covers` 文件夹即可，下次播放会重新生成。

**出了问题想反馈。**
把 `data/logs` 里对应日期的日志发出来最有用。程序崩溃时会在同一个目录额外留下 `crash-日期.log`。

## 关于

播放引擎用 libVLC，界面用 WPF-UI（Windows 11 原生 Fluent 风格，支持跟随系统主题切换明暗）。支持播放的格式多少，取决于 libVLC 能解多少。

更详细的技术说明、需求定义和各版本的改动记录都在 [REQUIREMENTS.md](REQUIREMENTS.md) 里。
